# Activity 2 – C/C++ Development Environment Setup

1. I used a MacBook with Apple Silicon to configure my C/C++ development environment.
2. I installed Visual Studio Code and the Microsoft C/C++ extension.
3. I verified the compiler using `clang --version`.
4. I created a C source file named `hello.c`.
5. I compiled the program using `clang hello.c -o hello`.
6. I executed the program using `./hello`.
7. The program successfully displayed `Hello, World!` in the terminal.
8. MSYS2 and MinGW are Windows-specific, so I used the native macOS compiler instead.
